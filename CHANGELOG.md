# История изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версия пакета берётся из `package.json`; тег `vX.Y.Z` ставится на коммит в `master`.

## 0.3.0 — 2026-10-07

Первый публичный выпуск.

Номер версии отражает долю покрытия публичного API ELMA365 `/pub/v1`: сервер
оборачивает 43 операции из 154 — около **28%** (≈0.3, что и отражено в версии).
Точное число даёт `npm run coverage`.

### Добавлено

- MCP-сервер для ELMA365 API: чтение схем и элементов, поиск (EQL с
  кросс-приложенческими подзапросами), пользователи и сотрудники, CRUD элементов
  (создание, изменение, смена статуса, массовое сохранение), работа с процессами
  (запуск, поиск экземпляров, чтение, прерывание, контекст, пропуск шага) и
  метаданные (разделы, решения, приложения, схемы процессов, модули, виджеты,
  контракты, отчёты, страницы, шаблоны документов, группы).
  Всего **45** инструментов.
- HTTP-транспорт (Streamable HTTP / SSE) с изоляцией сессий и endpoint `/health`.
- Кэш схем и статусов приложений (in-memory, LRU + TTL).
- Проверки: `npm run check` (типы + инвентарь инструментов против README и
  CHANGELOG), `npm run smoke` (сборка и старт сервера по stdio), `npm run probe`
  (живые вызовы на инстансе), `npm run coverage` (покрытие публичного API).
- CI на GitHub Actions: проверка workflow-файлов (actionlint), поиск утечек
  (gitleaks) по всей истории, `check`, `smoke`.
- Релизный конвейер: тег `vX.Y.Z` → проверки → публикация в npm → GitHub Release.

### Изменено

- Версия сервера (`serverInfo.version`) берётся из `package.json`, а не из
  константы в коде.
- Пакет готов к установке: `bin`, `files: ["dist"]`, `engines.node >=18`,
  `prepublishOnly`.
- Примеры в документации и в описаниях инструментов переведены на синтетические
  данные (без кодов проектов, страниц и задач, UUID и ФИО со рабочего стенда).

### Безопасность

- В репозитории и CI выполняется поиск утечек; отчёт об уязвимостях —
  см. [SECURITY.md](./SECURITY.md).
